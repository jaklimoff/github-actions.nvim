*github-actions* GitHub Actions at your fingertips

Browse the GitHub Actions runs of the current branch in a Telescope picker,
view their logs, watch them live, or open them in the browser.

Requirements:
- GitHub CLI (`gh`), installed and authenticated.
- telescope.nvim and plenary.nvim.

Commands:
- `:GithubActionsStatus` opens the picker for the current branch.

Picker keys:
- `<CR>`, `<C-l>` view the run logs in a terminal.
- `<C-a>` watch the run live.
- `<C-b>` open the run in the browser.

------------------------------------------------------------------------------
                                                         *GithubActions.setup()*
                         `GithubActions.setup`({opts})
Set up the plugin and merge the user options with the defaults.

Parameters ~
{opts} `(table|nil)` See |GithubActions.options|.

Usage ~
`require("github-actions").setup()` (add `{}` with your |GithubActions.options| table)

------------------------------------------------------------------------------
                                                *GithubActions.show_ci_status()*
                     `GithubActions.show_ci_status`({opts})
Show GitHub Actions CI status in a picker
Parameters ~
{opts} `(optional)` `(table)` Options to pass to the UI (e.g., { limit = 30 })

------------------------------------------------------------------------------
                                                      *GithubActions.view_run()*
                       `GithubActions.view_run`({run_id})
View a specific GitHub Actions run
Parameters ~
{run_id} `(number)` The run ID to view

------------------------------------------------------------------------------
                                                     *GithubActions.watch_run()*
                      `GithubActions.watch_run`({run_id})
Watch a specific GitHub Actions run
Parameters ~
{run_id} `(number)` The run ID to watch

------------------------------------------------------------------------------
                                              *GithubActions.open_run_browser()*
                   `GithubActions.open_run_browser`({run_id})
Open a specific GitHub Actions run in browser
Parameters ~
{run_id} `(number)` The run ID to open


==============================================================================
------------------------------------------------------------------------------
                                                         *GithubActions.options*
                            `GithubActions.options`
GithubActions configuration with its default values.

Type ~
`(table)`
Default values:
>lua
  GithubActions.options = {
      -- Show debug messages about what the plugin is doing.
      debug = false,
      -- UI used to display CI status (only "telescope" is supported for now).
      ui_method = "telescope",
      -- Maximum number of runs to fetch from GitHub Actions.
      telescope_limit = 20,
  }

<
